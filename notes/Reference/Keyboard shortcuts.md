# Keyboard shortcuts

| Keys | Does |
| --- | --- |
| ⌘K | Command palette · while typing, insert a link |
| ⌘F | Search notes |
| ⌘N / ⇧⌘N | New note / new folder |
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘B ⌘I ⌘U | Bold, italic, underline |
| ⌘\ | Clear formatting from the selection |
| ⌘⇧V | Paste with formatting |
| ⇧⌘P | Print / save as PDF |
| ⌘0 / ⌘1 | Reset zoom / fit to content |
| ⌘⇧D | Toggle dark mode |
| ⌘D / ⌫ | Duplicate / delete selection |
| V T P R L H | Select, text, draw, box, connector, pan |
| Tab | Next table cell · indent in a list |
