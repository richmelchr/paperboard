# Keyboard shortcuts

| Keys | Does |
| --- | --- |
| ⌘K | Command palette · while typing, insert a link |
| ⌘F | Search notes |
| ⌘N / ⇧⌘N | New note / new folder |
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘B ⌘I ⌘U | Bold, italic, underline |
| ⌘ | Clear formatting from the selection |
| ⌘⇧V | Paste with formatting |
| ⇧⌘P | Print / save as PDF |
| ⌘0 / ⌘1 | Reset zoom / fit to content |
| ⌘⇧D | Toggle dark mode |
| ⌘D / ⌫ | Duplicate / delete selection |
| V T P R L H | Select, text, draw, box, connector, pan |
| Tab | Next table cell · indent in a list |

I don't like the behavior of the toolbar droping down to another row when the
note-title text is longer. in the instance the tools don't fit, i want you to
move them to a drop down selector. the first set of tools to be grouped will be
the "tgroup" that contains the insert table tool. followed by the group with the
export, undo and zoom tools. then the font and text size selectors, then the
tools with bold, underline and text colors, then the tools that create boxes and
arrows. tools should never drop down to another line, just go off the side of
the page and allow me to scroll over to select them.
